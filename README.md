# House-Price-Prediction
Machine Learning project for predicting house prices using Linear Regression, Decision Tree, and Random Forest Regressor.

A Machine Learning project that predicts house prices based on property and location features using the California Housing Dataset.

## 🔧 Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

## 🤖 Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## 📊 Evaluation
Models are evaluated using MAE, MSE, RMSE, and R² Score. GridSearchCV is used to tune the best-performing model.

## 🔄 Workflow
Data Cleaning → EDA → Feature Engineering → Model Training → Evaluation → Hyperparameter Tuning → Prediction

## 🎯 Objective
To predict house prices accurately and identify the key features that influence house prices.
